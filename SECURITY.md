# Безопасность
- Версия 0.1 предназначена только для доверенной лабораторной LAN.
- Не публикуй порт сервера в интернет: нет аутентификации, TLS и защиты от злоупотреблений.
- Не добавляй пароли, токены или приватные ключи в Git.
- Разрешай доступ Python в брандмауэре только для частной сети.
- DNS на порту 53 может требовать администратора и конфликтовать с другими службами.
- Делай резервную копию `data/xnet.json` и каталога `sites/`.

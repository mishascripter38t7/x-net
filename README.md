# XNet v0.1 — рабочий локальный сетевой узел

XNet v0.1 запускает собственную локальную экосистему сервисов: XCore API, панель управления, XWeb (статические сайты), XDNS (DNS A-записи зоны `.xnet`), XSearch и реестр соседних узлов. Зависимостей Python нет — используется стандартная библиотека.

## Запуск Windows
1. Установи Python 3.10 или новее.
2. Распакуй архив.
3. Запусти `start_windows.bat`.
4. Открой `http://127.0.0.1:8080`.

Другие устройства в той же Wi-Fi/LAN сети могут открыть `http://IP_КОМПЬЮТЕРА:8080`. IP показывается в консоли. Разрешай Python в брандмауэре только для частной сети.

## Режимы
`python server.py` — HTTP на 8080 и тестовый DNS на UDP 5353.
`python server.py --port 8090` — изменить HTTP-порт.
`python server.py --no-dns` — отключить DNS.
`python server.py --dns-port 53` — попытка слушать стандартный DNS-порт (нужны права администратора и свободный порт).

## Реализовано
- XCore: REST API и локальная JSON-база `data/xnet.json`.
- XWeb: создание сайтов из панели; файлы лежат в `sites/`.
- XDNS: ответы A для зарегистрированных `.xnet`-доменов на IP текущего узла.
- XSearch: поиск по доменам и описаниям сайтов.
- XPeers: реестр URL других узлов.

## Важное ограничение DNS
Обычные настройки Windows/Android/iOS обычно принимают DNS на порту 53, а не 5353. Поэтому DNS на 5353 — тестовый сервис, а не автоматическая системная резолюция имён. Чтобы использовать `.xnet` как обычные имена в устройствах, нужно безопасно настроить DNS-клиент/роутер на узел XNet и запустить DNS на UDP 53. Это может требовать прав администратора; не меняй основной DNS роутера без понимания последствий. В текущей версии сайты открываются через `/site/<slug>`; полноценная маршрутизация по HTTP Host и HTTPS ещё впереди.

## API
- `GET /api/status`, `/api/sites`, `/api/domains`, `/api/peers`
- `GET /api/search?q=слово`
- `POST /api/sites` JSON: `{"slug":"blog","title":"Blog","description":"My site"}`
- `POST /api/domains` JSON: `{"domain":"blog.xnet","slug":"blog"}`
- `POST /api/peers` JSON: `{"address":"http://192.168.1.20:8080"}`
- `DELETE /api/domains/<domain>`, `DELETE /api/peers/<id>`

## Безопасность
Это лабораторный узел для доверенной LAN. Не пробрасывай его порты в публичный интернет: в v0.1 нет полноценной аутентификации, TLS, rate limiting или разграничения доступа. Не храни секреты в Git. Для тестирования с несколькими устройствами используй частную сеть.

# XNet

**XNet** — экспериментальный проект собственной сетевой экосистемы: локальные сервисы, DNS, сайты, инструменты и в перспективе соединённые сетевые узлы.

> Текущая версия — интерфейсный стартовый макет. Он не поднимает DNS, маршрутизацию, VPN или физическую сеть.

## Быстрый запуск

1. Распакуй архив.
2. Открой `index.html` в браузере.
3. Для публикации на GitHub Pages загрузи содержимое репозитория в GitHub и включи Pages в Settings → Pages.

Внешние зависимости для работы интерфейса не нужны. Google Fonts используется как необязательный источник шрифта; при отсутствии интернета будет системный шрифт.

## Структура

- `index.html` — интерфейс панели XNet.
- `styles.css` — тёмная адаптивная тема.
- `app.js` — поиск, меню, настройки и интерактивность.
- `docs/` — архитектура, дорожная карта и безопасность.

## Компоненты экосистемы

- **XCore** — базовые сервисы и API.
- **XDNS** — DNS и внутренние доменные зоны.
- **XWeb** — хостинг и веб-пространство.
- **XBrowser** — браузерная интеграция.
- **XSearch** — поиск по ресурсам.
- **XProtocols** — правила обмена данными.

## Статус

Сейчас готова стартовая веб-панель и документационная структура. Серверная часть и сетевые службы ещё не реализованы.

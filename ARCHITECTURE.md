# Архитектура XNet v0.1
- **XCore** — HTTP API, конфигурация и JSON-хранилище.
- **XDNS** — минимальный DNS responder для A-записей `.xnet`.
- **XWeb** — статические сайты из каталога `sites/`.
- **XSearch** — поиск по реестру доменов и метаданным сайтов.
- **XPeers** — реестр адресов соседних узлов; автоматическая репликация пока не реализована.
- **Control Center** — браузерная панель для управления узлом.

Транспорт пока использует обычный TCP/IP в локальной сети. XNet отделяет сервисы и адресное пространство, но не имеет собственной глобальной физической сети.
